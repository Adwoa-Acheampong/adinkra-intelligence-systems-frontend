## Maintenance Rule

The mindmap is not a backlog decoration. Before a new route, metric, entity, workflow, or feature is built:

1. Locate its parent branch.
2. Confirm its user, scope, decision, source event, evidence, and action.
3. Add any missing node to this map.
4. Update the living system map.
5. Only then create or change the implementation.
